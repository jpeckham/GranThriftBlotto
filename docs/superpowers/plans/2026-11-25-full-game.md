# Gran Thrift Blotto Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the full approved Roblox thrift heist game, with reproducible source builds and honest verification evidence.

**Architecture:** Pure shared Luau rules own gameplay transitions and calculations. Roblox server services adapt the rules to characters, prompts, security, economy and generated map geometry. Client scripts render UI and effects from server snapshots.

**Tech Stack:** Luau, Roblox Studio, Rojo, Lune standalone Luau tests; no runtime packages.

**Spec:** `docs/superpowers/specs/2026-11-24-gran-thrift-blotto-design.md`

## Global Constraints

- Native Luau with Rojo; up to 10 players, 2 cops at four or more players.
- Heist clock is 240 seconds; extracted cargo threshold is $500.
- Manager stun is 3 seconds; Hoarder adds 40% capacity; Turbo Walker adds 20% parking speed.
- Server owns all gameplay and economic state; validate action type, phase, role, distance, line of sight and cooldown.
- Preserve non-alcoholic Fizz terminology and bloomers outside dresses.
- No live paid purchases without configured owner product IDs; no simulated success.
- Keep work here in Codex with no new Beluga dependencies.

## Review Focus

- Fizz capacity expiry cannot delete collected loot or permit overcapacity pickup (Task 1).
- Captures, deaths, disconnects and late joins cannot duplicate loot/rewards or strand the round (Tasks 1/3).
- Remote events cannot grant arbitrary currency, capture across walls, or buy without funds (Tasks 3/5).
- DataStore load failure must not overwrite saved profiles; repeat receipts cannot double-grant (Task 5).
- Camera and movement effects must reset when the character or round changes (Task 4, Studio verification).

## File structure and interfaces

`src/ReplicatedStorage/Shared/{Config,Catalog,Rules,Match,Profile}.luau`:
configuration/catalogs, pure gameplay calculations, match state/actions, persistent profile transformations.
`src/ServerScriptService/{Main.server,Core/Map,Core/Characters,Core/Game,Core/Economy}.luau`:
entry point, world generation, rig visuals/movement, authoritative runtime, DataStore/Marketplace adaptation.
`src/StarterPlayer/StarterPlayerScripts/{Main.client,UI,Effects}.luau`:
responsive UI/input, snapshot presentation, camera and Fizz effects.
`tests/{rules,match,profile,map}.luau`, `tests/run.luau`: standalone tests of production modules and generated Roblox instances via Lune.
`default.project.json`, `rokit.toml`, `scripts/{test,build}.ps1`, `README.md`, `docs/acceptance.md`:
reproducible tools/build, controls and verification record.
